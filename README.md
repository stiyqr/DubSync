# DubSync

A multi-model AI pipeline that synchronizes dubbed audio with live-action video, supporting multiple faces and dynamic speaker detection. Combines face recognition and speaker diarization to accurately match voices to on-screen characters and achieve real-time multi-actor lip synchronization.

Use the notebook below to run **DubSync** without setting up the full project environment.
